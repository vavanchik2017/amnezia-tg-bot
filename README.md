# 🛡 AmneziaWG Telegram Bot

Telegram-бот для управления контейнером AmneziaWG (`amneziawg-go`) на вашем Linux VPS.

## 🚀 Возможности (MVP)

1. **Выпуск новых конфигов в двух форматах:**
   - **Native AmneziaWG (`.conf`)**: стандартный конфигурационный файл с параметрами обфускации (`Jc, Jmin, Jmax, S1, S2, H1..H4`) для WireGuard / AmneziaWG.
   - **Amnezia VPN (`.vpn`)**: JSON-профиль и ссылка `vpn://` для официального клиента Amnezia VPN.
   - **QR-коды**: генерация QR-кодов прямо в чате для удобного сканирования со смартфона.
2. **Аутентификация администратора:**
   - Доступ строго по списку Telegram ID (`ADMIN_IDS`). Неавторизованные пользователи получают отказ с отображением их ID.
3. **Управление пирами (клиентами):**
   - Просмотр списка выпущенных конфигов с онлайн-статусом (активен, последний handshake, трафик).
   - Временное отключение (пауза) пира без удаления.
   - Быстрое повторное включение.
   - Полный отзыв (удаление) пира из WireGuard и базы данных.
4. **Сбор статистики трафика и срезы:**
   - Фоновый процесс опрашивает счетчики интерфейса (по умолчанию раз в 5 минут).
   - Поддерживает расчет дельты при перезагрузках контейнера или сбросе интерфейса.
   - Срезы по трафику (Rx / Tx / Всего):
     - **За 24 часа** (день)
     - **За 7 дней** (неделя)
     - **За 30 дней** (месяц)
     - **За 365 дней** (год)
     - **За всё время**
   - Статистика доступна как суммарно по всему серверу, так и индивидуально по каждому клиенту.

## 📋 Требования

- Linux VPS (Ubuntu, Debian или любой дистрибутив с Docker).
- Установленный Docker и Docker Compose.
- Запущенный контейнер с AmneziaWG (по умолчанию `amnezia-awg2`).
- Telegram Bot Token от [@BotFather](https://t.me/BotFather).

## 🛠 Установка и запуск на сервере

### 1. Клонирование репозитория

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ> /opt/amnezia-bot
cd /opt/amnezia-bot
```

### 2. Настройка переменных окружения

Создайте файл `.env` из примера:

```bash
cp .env.example .env
nano .env
```

Заполните ключевые переменные:
* `BOT_TOKEN` — токен бота от BotFather.
* `ADMIN_IDS` — ваш Telegram ID (число, можно узнать у [@userinfobot](https://t.me/userinfobot) или просто запустив бота и нажав `/start`).
* `VPN_CONTAINER_NAME` — имя контейнера с AmneziaWG (по умолчанию `amnezia-awg2`).
* `SERVER_HOST` — публичный IP вашего VPS (если оставить пустым, бот определит его сам через внешний сервис).
* `SERVER_PORT` — порт (если оставить пустым, бот считает его из `wg show`).

### 3. Запуск через Docker Compose

```bash
docker compose up -d --build
```

### 4. Просмотр логов

```bash
docker compose logs -f amnezia-bot
```

## 📂 Структура проекта

```text
amnezia-bot/
├── .env.example              # Пример файла с переменными окружения

├── .gitignore                # Игнорируемые файлы (БД, .env, кэш)
├── Dockerfile                # Сборка контейнера бота (Python 3.11-slim)
├── docker-compose.yml        # Конфигурация запуска сервиса
├── requirements.txt          # Python-зависимости (aiogram, docker, cryptography, qrcode)
├── README.md                 # Документация
└── bot/
    ├── __init__.py
    ├── main.py               # Точка входа, запуск бота и фоновых сервисов
    ├── config.py             # Загрузка и валидация настроек (.env)
    ├── database/
    │   ├── db.py             # Инициализация SQLite базы данных
    │   └── models.py         # Модели и запросы (пиры, снапшоты, агрегация трафика)
    ├── services/
    │   ├── docker_service.py # Взаимодействие с контейнером amneziawg-go через docker.sock
    │   ├── awg_service.py    # Генерация ключей X25519, .conf, .vpn JSON и QR-кодов
    │   └── stats_service.py  # Фоновый сборщик дельт трафика
    └── handlers/
        ├── common.py         # Фильтры прав (IsAdmin) и общие клавиатуры
        ├── admin.py          # /start, меню, проверка статуса сервера
        ├── peers.py          # Создание, список, пауза, удаление и выдача конфигов
        └── stats.py          # Срезы статистики (сервер и конкретный пир)
```

## 🔒 Безопасность

* Бот монтирует сокет Docker (`/var/run/docker.sock`) для выполнения команд внутри контейнера VPN (`wg show`, `wg set`).
* Все приватные ключи хранятся в защищенной локальной базе SQLite (`/app/data/bot.db`), смонтированной в каталог `./data`.
* Файл `.env` и каталог `./data` добавлены в `.gitignore` и никогда не попадут в репозиторий.
